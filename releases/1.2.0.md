## Arches Controlled Lists 1.2.0 Release Notes

### New Features

- Add CLI tool for extracting domain values from nodes into controlled lists [#257](https://github.com/archesproject/arches-controlled-lists/pull/257)
- Add CLI tool for converting domain/domain-list nodes into reference datatype nodes [#257](https://github.com/archesproject/arches-controlled-lists/pull/257)
- Add ETL module for updating concept and domain tile values to reference datatype instances [#257](https://github.com/archesproject/arches-controlled-lists/pull/257)

### Performance Improvements

### Bug fixes

- Normalize whitespace-only lines in `__arches_migrate_collections_to_clm.sql` to stop a phantom `AlterSQL` migration from being generated on every `makemigrations`.
- Cope with default values living on the node rather than the cardxnodexwidget [#257](https://github.com/archesproject/arches-controlled-lists/pull/257)

### Breaking changes

- Switches from `arches-component-lab` to `arches-vue-components`. [#265](https://github.com/archesproject/arches-controlled-lists/pull/265)

    - `arches_component_lab` has been replaced by `arches_vue_components` in `INSTALLED_APPS` (`arches_controlled_lists/settings.py`).
    - The URL include for the component library has changed from `arches_component_lab.urls` to `arches_vue_components.urls` (`arches_controlled_lists/urls.py`).
    - Any project code importing from `@/arches_component_lab/...` must be updated to import from `@/arches_vue_components/...` instead.
    - The `WidgetMapping` migration dependency has moved from the `arches_component_lab` app to the `arches_vue_components` app; you'll need to run migrations after upgrading.

### Deprecations

### Upgrading Arches Controlled Lists

1. Upgrade python package
    ```
    pip install --upgrade arches-controlled-lists==1.2.0
    ```

1. Switch your project from `arches-component-lab` to `arches-vue-components`:

    - Update your project's Python dependencies to remove `arches-component-lab` and add `arches-vue-components>=1.0.0`, then reinstall.

    - Update your project's `package.json` to remove the `arches-component-lab` dependency and add:
        ```json
        "arches-vue-components": "archesproject/arches-vue-components#dev/1.0.x"
        ```
        then reinstall your frontend dependencies:
        ```
        rm -r node_modules; rm package-lock.json
        npm install
        ```

    - In your project's `settings.py`, replace `arches_component_lab` with `arches_vue_components` in `INSTALLED_APPS`.

    - In your project's `urls.py`, replace the `arches_component_lab.urls` include with `arches_vue_components.urls`.

    - Update any project code importing from `@/arches_component_lab/...` to import from `@/arches_vue_components/...` instead.

1. Run migrations
    ```
    python manage.py migrate
    ```

1. Update webpack build
    ```
    npm run build_development
    python manage.py collectstatic
    ```

1. If you are running Arches on Apache, restart your server:
    ```
    sudo service apache2 reload
    ```

### Upgrading Arches Controlled Lists

1. Upgrade python package
    ```
    pip install --upgrade arches-controlled-lists==1.3.0
    ```

2. Run migrations
    ```
    python manage.py migrate
    ```

3. It is recommended that you re-export your lists via skos if you have configured them as searchable.
    ```
    python manage.py packages -o export_controlled_lists -f skos-rdf -d {MY_PROJECT}/pkg/reference_data/controlled_lists
    ```

4. Update webpack build
    ```
    npm run build_development
    python manage.py collectstatic
    ```

5. If you are running Arches on Apache, restart your server:
    ```
    sudo service apache2 reload
    ```
